Como começar

Crie um projeto acima. Em Especificações, edite o Product Brief, os requisitos e a arquitetura. Em Tarefas, organize o trabalho. Exporte os arquivos Markdown e coloque-os no repositório SPECTION para revisão.

A integração do motor Python e o chat com modelos são uma etapa futura.
